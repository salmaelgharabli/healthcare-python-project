# Healthcare Patient Visit Analysis
## Project Overview

This beginner Python project analyzes healthcare patient visit data using Python.

The project focuses on patient visits, wait times, departments, patient outcomes and healthcare performance indicators.

## Tools Used
- Python
- Pandas
- Matplotlib
- CSV data

## Analysis Performed

The project calculates:

- Total number of patients
- Average wait time
- Shortest wait time
- Longest wait time
- Median wait time
- Top department by number of visits
- Number of long-wait patients
- Patient outcomes
- Average wait time by department
- Top 3 longest patient waits
- Healthcare KPIs

## Visualizations

The project creates charts showing:

- Patients by Department
- Wait-time distribution
- Patient outcomes
- Average wait time by department
- Top longest patient waits

## Sample Results

- Total patients: 8
- Average wait: 45 minutes
- Shortest wait: 15 minutes
- Longest wait : 90 minutes
- Top department: Emergency
- Long-wait patients: 2
- Long-wait percentage: 25%

## Purpose

This project was created as a beginner healthcare data-analysis portfolio project to practice Python, Pandas, data cleaning, statistics, data visualization.
